npm install -g @taptap/cli               # 安装（包约 37MB）
taptap-cli update --skills-layout suite  # 安装 AI Skills，并合并为单个 taptap-suite
taptap-cli auth login                    # 授权

插件会自动搜索 PATH 以及 nvm / proto / volta 等版本管理器下的全局目录，装完即可用，通常不需要手动配置 PATH。

AI Skills 合并为单个 taptap-suite 后，它与本插件手册的重叠面最小；若你还要单独使用那些 skill，把 --skills-layout 换成 separate 即可。
